# KUST WSC27 Electronic Team

Bridgestone World Solar Challenge 2027, Car No. 82.

- [`matlab/`](matlab/) — SILS digital twin: solar array → MPPT → battery → inverter/motor → vehicle dynamics. See `matlab/README.md` for usage and modelling assumptions.
- [`vcu/`](vcu/) — WaveSculptor22 VCU (Python, CAN): torque/speed command, protection, CAN accelerator pedal, monitoring/logging. See `vcu/README.md`.
